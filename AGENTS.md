# Repository instructions

Use [config/AGENTS.md](config/AGENTS.md) for this repository unless the same policy is already in context. It defines ownership, completion, lazy-intel routing and safety; do not reload it before every edit.

This repository ships host-policy templates, not an automatic host-policy installer. Do not copy configuration into the user's agent directory, activate an extension, or change approvals as a side effect of editing these files.

For policy edits, use [POLICY-VALIDATION.md](docs/POLICY-VALIDATION.md). For runtime changes, use [IMPLEMENTATION-WORKORDER.md](docs/IMPLEMENTATION-WORKORDER.md). Read only the reference needed for the current decision.
